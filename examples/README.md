# Examples

- `synthetic_end_to_end.py` — consensus selection, null-selection control,
  stability, permutation test and classical benchmarks on synthetic data
  (runs in < 2 min, no data needed).

`public_small_n.py` compares the plug-in conditional-MI objectives (`cmi`,
`cmi_cr`), the Mücke plug-in objective and the corrected estimators under the
label-permutation control on public datasets.
